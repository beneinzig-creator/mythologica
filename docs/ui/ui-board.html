Mythologica UI Board

Where to find game UI inspiration, and which games to study for each screen and mechanic in Mythologica: the combat board, card frames, the map, the draft and the realm-tinted backgrounds.

Sources

Where to look

Start with Game UI Database. Use the portfolio sites for concept-level polish, and the talks for the reasons behind the designs.

Screenshot databases

Game UI DatabaseStart here

The largest archive of real shipped game screens. Filter by screen type, genre, colour and typeface.

Try: filter to card games and roguelites, then the screen types for map, rewards, deck and combat HUD.

Interface In Gameinterfaceingame.com

A curated gallery that includes video clips, so you can see transitions, hover states and motion as well as still frames.

Try: look at how card play and reward screens animate in and out.

HUDS+GUIShudsandguis.com

A design blog of standout HUD and interface work, including film UI. It leans toward art direction and profiles the designers.

Try: browse for ornament and framing ideas rather than layouts.

Portfolios and community

ArtStationartstation.com

Professional concept and UI art, often from studio artists. Strong for card frames, icons and fantasy ornament.

Search: "card game UI", "card frame", "fantasy UI kit", "rune icons".

Behancebehance.net

Full case studies that show wireframes, iterations and final screens, not just the polished result.

Search: "game UI", "card game UX", "roguelike UI".

Dribbbledribbble.com

Fast to scan and very polished. Many shots are concepts that were never shipped, so check that they would hold up in play.

Tags: game_ui, game_hud, card_game.

r/GameUIreddit.com

Shared finds, critique threads and work in progress. A good place to post a Mythologica screen for feedback.

Try: search the subreddit for "deckbuilder" and "card".

Pinterestpinterest.com

The quickest way to collect images from all of the above into one board per realm.

Try: one board each for Greek, Norse and Chinese styling.

Type and colour

Fonts In Usefontsinuse.com

An archive of typefaces identified in real work, including video games. Useful when you want to know what a game's title or card font is.

Try: browse the video game category for display faces.

Google Fontsfonts.google.com

Free faces that can load inside a single-file game. Good candidates for inscription-style card titles.

Try: Cinzel, Marcellus, Cormorant, Uncial Antiqua, Ma Shan Zheng.

Lospec paletteslospec.com

A large library of tight, game-tested colour palettes. Handy for picking a set of colours per realm and per opponent background.

Try: search "bronze", "ice", "lacquer".

Talks and reading

GDC Vaultgdcvault.com

Talks from UI and UX leads at studios, many of them free. They explain why a layout works, which a screenshot cannot.

Search: "UI", "UX", "card game", "Hades", "Slay the Spire".

The Gamer's Brainbook

Celia Hodent's book on how players perceive, learn and remember. It is the usability side of game UI.

Useful for: teaching offering, tapping and trumps without a long tutorial.
